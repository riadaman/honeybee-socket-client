🔧 Setup Instructions
1. Clone the Repository
   - git clone git@github.com:riadaman/honeybee-socket-client.git
   - cd honeybee-socket-client
2. Install Dependencies
   - npm install socket.io-client@2.4.0
3. Update Credentials
    Open socketTest.js and update these two values with your valid session data:
    - const userId = "appId_UserId";         
    - const token = "YOUR_SESSION_TOKEN";
▶️ Run the Client
node socketTest.js
